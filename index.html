Jak działa HTML, CSS i JavaScript?

Kod → Podgląd → Skopiuj i wypróbuj u siebie

1. Podstawowe znaczniki HTML (nagłówki i formatowanie tekstu)
<h1>Witaj w świecie HTML!</h1>
<h2>Podstawowe znaczniki</h2>
<p>To jest <b>pogrubiony</b> tekst.</p>
<p>To jest <u>podkreślony</u> tekst.</p>
<p>To jest <i>pochylony</i> tekst.</p>

2. Lista numerowana + style bezpośrednio w tagach
<h1>Moje ulubione filmy</h1>
<ol>
  <li style="color: #e11d48;">Incepcja</li>
  <li style="color: #2563eb;">Matrix</li>
  <li style="color: #16a34a;">Interstellar</li>
  <li style="color: #9333ea;">Pulp Fiction</li>
  <li style="color: #ea580c;">Shrek</li>
</ol>

  2. Matrix
  3. Interstellar
  4. Pulp Fiction
  5. Shrek
3. CSS – klasy (każda klasa zmienia tylko jedną rzecz)
<style>
.duzy { font-size: 22px; }
.czerwony { color: #dc2626; }
.zielone-tlo { background-color: #bbf7d0; }
.pogrubiony { font-weight: bold; }
.kursywa { font-style: italic; }
</style>

<ul>
  <li class="duzy">Duży tekst</li>
  <li class="czerwony">Czerwony tekst</li>
  <li class="zielone-tlo">Zielone tło</li>
  <li class="pogrubiony kursywa">Pogrubiony i pochylony</li>
  <li class="duzy czerwony zielone-tlo">Wszystko naraz!</li>
</ul>
  • Duży tekst
  • Czerwony tekst
  • Zielone tło
  • Pogrubiony i pochylony
  • Wszystko naraz!
4. Ćwiczenie – znajdź błędy w HTML i CSS
<style>
.niebieski {
  color: #2563eb;
  font-weight: bold;
  padding: 4px;
}
.wyrozniony {
  background-color: #fef3c7;
  border-radius: 4px;
  font-style: italic;
}
</style>

<h1 style="color: #dc2626;">Moje hobby</h1>
<h2 style="color #16a34a;">Co lubię robić?</h2>

<ol>
  <li class="niebieski">Czytanie</li>
  <li class="wyrozniony">Rysowanie</li>
  <li class="niebeski">Jazda na rowerze</li>
</ol>

<ul>
  <li class="wyrozniony">Książki</li>
  <li class="niebieski">Muzyka</li>
  <li class="wyrozniony">Film</li>
</ul>

Moje hobby

Co lubię robić?

  1. Czytanie
  2. Rysowanie
  3. Jazda na rowerze
  • Książki

  • Film
5. JavaScript – zmiana kolorów po kliknięciu
<p id="p1">Paragraf pierwszy</p>
<p id="p2">Paragraf drugi</p>
<p id="p3">Paragraf trzeci</p>

<button onclick="zmienKolory()">Zmień kolory!</button>

<script>
function zmienKolory() {
  document.getElementById("p1").style.color = "red";
  document.getElementById("p2").style.color = "blue";
  document.getElementById("p3").style.color = "green";
}
</script>
